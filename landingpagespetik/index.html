Software Engineering Sertifikasi BNSP Junior Web Dev

Rekayasa Web Fullstack & Arsitektur Backend Modern

Mahasantri jurusan PPL dilatih merancang sistem informasi dari nol: membangun antarmuka web yang elegan dan responsif, merancang arsitektur basis data relasional yang kokoh, membuat RESTful API yang aman, serta menguji performa software sebelum deployment ke server produksi.

Semester 1: Fondasi & Frontend

Algoritma logika, Git/GitHub, HTML5, CSS3, Tailwind CSS, serta JavaScript interaktif (DOM & Fetch API).

Semester 2: Backend & Database

Python Flask, perancangan SQL (SQLite & MySQL), RESTful API, otentikasi user, & sertifikasi resmi BNSP.

Prospek Karier Lulusan:

Junior Web Developer Backend API Programmer Database Administrator Fullstack Freelancer

Portofolio Capstone Mahasantri PPL:

  • Sistem Informasi Monitoring Santri & Beasiswa Terpadu
  • Aplikasi Perpustakaan & Reservasi Buku Daring Berbasis Web
  • Landing Page Katalog Kuliner Nusantara Terintegrasi Checkout WhatsApp
  • Platform Ujian Online Realtime Berbasis Bank Soal
Marketing & Growth Sertifikasi BNSP Digital Marketer

Strategi Pertumbuhan Bisnis, Konten Kreatif & Iklan Berbayar

Mahasantri jurusan Digital Marketing dilatih menjadi praktisi pemasaran online yang mampu meramu pesan bernilai jual tinggi, mengelola akun media sosial secara profesional, mengoptimasi mesin pencari (SEO), hingga mengeksekusi kampanye iklan berbayar (Meta Ads & TikTok Ads) dengan Return on Ad Spend (ROAS) optimal.

Semester 1: Riset & Konten

Riset audiens/buyer persona, copywriting formula AIDA, desain grafis promosi, & produksi video komersial.

Semester 2: Paid Ads & Funnel

Manajemen iklan Meta Ads, TikTok Ads, SEO On/Off page, funnel konversi, & uji kompetensi resmi BNSP.
